# Apoca Drive

- `website/` : le site client (apocadrive.web.app)
- `public/` : l'application (apoca-drive.web.app)
- `functions/` : les notifications et l'envoi des devis
- `firestore.rules` : les règles de la base de données

Chaque modification envoyée sur `main` est mise en ligne automatiquement
(onglet **Actions** de GitHub, environ 2 minutes).
